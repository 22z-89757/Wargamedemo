# 单位浮动血条验收记录

验收日期：2026-10-31。Unity 版本：6000.3.27f1。场景：Map1。

## 最终配置

- 独立根级 UnitHealthBarCanvas，Screen Space Overlay，排序 -1；BattleUICanvas 排序 0。
- 基础尺寸 96×10，世界头顶偏移 2，距离阈值 10/30，近远缩放 1.1/0.65。
- 总格数 `ceil(MaxHealth)`，红格数 `ceil(clamp(Health/MaxHealth,0,1) × 总格数)`；底层 Health/MaxHealth 保留 float。
- 背景和矩形红色填充使用 Image；分隔线使用一个带 CanvasRenderer 的 Graphic。所有 Graphic 禁用 raycastTarget，血条 Canvas 无 GraphicRaycaster。
