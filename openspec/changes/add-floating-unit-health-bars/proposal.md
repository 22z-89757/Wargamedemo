# 提案：单位浮动血条

## 为什么

战斗中缺少随单位移动的生命值显示，玩家难以直接比较己方与敌方的剩余生命。增加按最大生命值分格、随镜头距离缩放的头顶血条，让受伤程度与生命容量在棋盘上可见。

## 变更内容

- 为场景管理的所有存活战斗单位显示浮动血条，覆盖玩家与敌方，不受当前回合、选中状态、AP 或是否具有射击能力影响。
- 使用统一的基础长度，以 `ceil(MaxHealth)` 个等宽格子表示生命容量。红色填充严格按整格显示：将 `Health / MaxHealth` 限制在 0～1 后乘以总格数，再向上取整为已填充格数；例如 `7.5/10` 显示 8 格。底层生命属性保留小数，显示取整不回写属性。
- 血条跟随单位实际世界位置，以摄像机距离进行有上下限的近大远小缩放，保持屏幕水平；基础尺寸、头顶偏移和缩放参数可在 Inspector 配置。
- 建立独立于 `BattleUICanvas` 的 `UnitHealthBarCanvas`，绘制在现有 HUD 下方，血条不拦截棋盘点击、触摸或相机手势。
- 单位死亡、销毁及战斗清理时移除血条；投影点位于镜头后方、裁剪范围外或屏幕外时隐藏，重新进入时恢复。

## 能力

### 新增能力

- `unit-health-bars`：定义战斗单位血条的覆盖范围、生命值分格与填充、世界位置跟随、距离缩放，以及独立 UI 层和生命周期行为。

### 修改能力

无。现有远程攻击、LOS 与目标列表规格保持原有行为。

## 影响

- 新增战斗血条表现组件和可复用的 uGUI 血条视图；复用现有 uGUI，不引入新包或外部美术资源。
- 在 `BattleSceneManager` 接入血条层初始化、单位集合刷新与清理；读取 `Unit`、`CharacterAttribute` 的既有状态与事件，不改变生命值计算。
- 通过 `BattleCameraRig.OutputCamera` 投影，跟随 `UnitVisualController` 驱动的实际 Transform；在 `Map1.unity` 装配独立 Canvas 和显式引用。
- 增补 EditMode、PlayMode 验证以及脚本说明，覆盖两阵营、属性变化、镜头和输入穿透。
