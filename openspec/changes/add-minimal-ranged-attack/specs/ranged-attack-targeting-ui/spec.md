# Spec Delta

## Purpose

为远程攻击提供清晰的玩家操作入口：在屏幕左侧列出当前选中己方单位能够攻击的敌人，允许切换目标并查看命中率，只有确认目标后才通过独立的开火按钮执行射击。

## ADDED Requirements

### Requirement: 左侧列表只显示当前单位的可瞄准敌人

系统 SHALL 在屏幕左侧显示当前选中且可下达命令的己方单位对应的可瞄准敌人列表；列表只包含存活、敌对、在射程内、LOS 畅通且射击能力可检查的目标，并按稳定顺序显示目标名称。

#### Scenario: 选中己方单位后生成列表

- **WHEN** 用户选中一个存活且处于玩家回合的己方单位
- **THEN** 左侧列表刷新为该单位当前可瞄准的敌人；没有目标时显示空列表状态

#### Scenario: 切换己方单位

- **WHEN** 用户选中另一个己方单位
- **THEN** 列表立即替换为新单位的可瞄准敌人，之前的目标选择和命中率展示不再沿用

#### Scenario: 目标状态改变

- **WHEN** 单位移动、障碍变化、回合切换、AP 变化或单位死亡导致可瞄准集合改变
- **THEN** 列表刷新并移除不再合法的目标

### Requirement: 点击列表项只切换射击目标

系统 SHALL 允许用户点击左侧列表项选择目标，并显示该目标的名称与命中率；切换列表项不得直接扣 AP、造成伤害或触发射击。

#### Scenario: 选择一个列表目标

- **WHEN** 用户点击一个可瞄准敌人的列表项
- **THEN** 该项成为当前射击目标，界面显示其命中率，AP 保持不变

#### Scenario: 选择失效目标

- **WHEN** 已选目标在点击后死亡、移动或因 LOS/射程变化失效
- **THEN** 界面清除该目标选择并隐藏开火按钮

### Requirement: 开火按钮只在目标有效时可用

系统 SHALL 仅在存在当前选中的合法目标、攻击者仍有至少 1 AP 且射击能力可以激活时显示并启用开火按钮；点击按钮 SHALL 调用射击执行流程，而不是由目标列表或单位点击直接开火。

#### Scenario: 合法目标显示开火按钮

- **WHEN** 当前选中目标通过全部射击检查且攻击者 AP 足够
- **THEN** 开火按钮显示并可点击

#### Scenario: 没有合法目标时隐藏按钮

- **WHEN** 没有选中目标、目标列表为空、攻击者不是玩家回合或 AP 不足
- **THEN** 开火按钮隐藏或不可交互，且点击无射击效果

#### Scenario: 点击开火后刷新界面

- **WHEN** 用户点击可用的开火按钮
- **THEN** 系统执行一次射击并刷新 AP、命中结果、目标生命值和列表；目标死亡时从列表移除并清除选择
