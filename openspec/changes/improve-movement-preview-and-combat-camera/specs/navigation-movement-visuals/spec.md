# Spec Delta

## ADDED Requirements

### Requirement: 拖动移动预览显示起终点直线
系统 SHALL 在玩家拖动预览合法移动目标时，以单位当前世界位置和候选目标格中心之间的直线显示预览；预览几何长度 SHALL 对应两端点的欧式距离，不得沿棋盘格路径逐格折线绘制。

#### Scenario: 预览路径跨越多个棋盘格
- **WHEN** 玩家拖动单位到一个合法目标格，棋盘逻辑路径包含多个转折
- **THEN** 预览组件仍以一条直线连接单位当前位置和目标格中心

#### Scenario: 直线预览不改变移动规则
- **WHEN** 起终点直线穿过棋盘逻辑障碍或比合法棋盘路径更短
- **THEN** 系统仍按棋盘可达性判断是否显示可提交目标，并按原逻辑路径计算 AP 和移动占格；预览线不授权穿越障碍

#### Scenario: 预览目标取消或失效
- **WHEN** 玩家结束拖动、目标格不可达或当前单位失去移动资格
- **THEN** 系统清除直线预览，且不提交移动或消耗 AP
