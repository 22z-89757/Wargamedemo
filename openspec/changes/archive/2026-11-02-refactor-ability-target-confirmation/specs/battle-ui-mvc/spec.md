# Spec Delta

## MODIFIED Requirements

### Requirement: 战斗 UI 使用统一状态驱动展示

战斗 UI SHALL 从统一的战斗状态读取回合、选中单位、AP、能力和目标预览；视图 SHALL 只渲染状态并发出用户意图，不能直接修改单位属性、回合状态或造成战斗效果。

#### Scenario: 战斗状态变化后视图同步
- **WHEN** 回合、选中单位、AP、能力可用性或目标预览发生变化
- **THEN** 相关视图在下一次刷新中显示最新状态，且不保留已失效的选择或操作状态

#### Scenario: 视图事件提交用户意图
- **WHEN** 用户点击目标、能力、确认或结束回合控件
- **THEN** UI 将意图交给战斗控制流程，由战斗系统执行校验和提交，视图本身不直接扣 AP 或修改战斗属性

### Requirement: 右侧显示选中玩家单位信息和能力操作

系统 SHALL 在屏幕右侧显示当前选中且可下达命令的玩家单位名称、当前 AP/最大 AP 和其全部已授予且非移动的能力；每项能力 SHALL 显示中文名称、当前 AP 消耗及实时可用状态，并从能力系统读取状态而非复制判断规则。点击能力操作 SHALL 表示请求使用该能力；无目标或自身目标能力在重新验证后立即提交，Unit 目标能力则进入目标选择和确认流程。

#### Scenario: 选中单位后刷新信息
- **WHEN** 玩家选中一个存活的己方单位
- **THEN** 右侧面板显示该单位名称、AP/最大 AP 和全部非移动的已授予能力，不显示移动能力

#### Scenario: 切换单位清除旧信息
- **WHEN** 玩家切换到另一个己方单位或取消选择
- **THEN** 右侧面板立即替换为新单位信息，或显示无选中单位状态，不沿用旧单位能力按钮

#### Scenario: 能力状态随属性变化
- **WHEN** 选中单位的 AP、回合资格、冷却、次数或阻挡标记变化
- **THEN** 对应能力项更新可用状态和原因，且不会执行能力

#### Scenario: 点击无目标或自身目标能力
- **WHEN** 玩家点击一个无目标或自身目标能力
- **THEN** 控制器重新验证当前单位、回合与能力状态，通过后立即向能力系统提交一次激活，不显示目标列表或确认窗口

#### Scenario: 点击 Unit 目标能力
- **WHEN** 玩家点击一个当前可请求使用的 Unit 目标能力
- **THEN** 该能力成为待用能力，显示其合法目标列表；能力尚未激活且 AP 未扣除

#### Scenario: 点击能力控件提交激活意图
- **WHEN** 玩家点击一个当前可用的能力操作
- **THEN** None/Self 能力立即提交；Unit 射击能力只准备目标选择，确认后才向能力系统提交并完成最终校验与 AP 扣除

### Requirement: 只读与交互 UI 分属不同 Canvas

系统 SHALL 将不需要交互的回合信息、选中单位信息、提示和结果放在只读 Canvas，将目标列表、能力操作、旋转、结束回合和能力/结束回合确认控件放在交互 Canvas；只读 Canvas 不得通过 GraphicRaycaster 或 Graphic raycast 阻挡棋盘输入。

#### Scenario: 只读 UI 不阻挡棋盘
- **WHEN** 指针按下或拖动经过回合信息、能力状态文本或结果提示
- **THEN** 输入系统将其视为非 UI 阻挡区域，棋盘选择、移动或相机手势仍按原规则处理

#### Scenario: 交互控件阻挡棋盘
- **WHEN** 指针按下交互 Canvas 中的目标按钮、能力按钮、结束回合按钮或确认按钮
- **THEN** 输入系统将其识别为 UI 操作，棋盘手势不应同时提交

#### Scenario: Canvas 装配错误被拒绝
- **WHEN** 只读 Canvas 带有会拦截输入的 GraphicRaycaster 或其 Graphic 开启 raycast
- **THEN** 战斗 UI 初始化报告明确配置错误，不静默以错误分层运行

## ADDED Requirements

### Requirement: Unit 目标能力通过目标选择和确认后激活

当前被请求使用的 Unit 目标能力 SHALL 驱动左侧目标列表；选择目标只建立待确认操作，系统 SHALL 在确认后重新验证能力和目标并最多激活一次。

#### Scenario: 目标列表按需显示
- **WHEN** 玩家请求使用一个 Unit 目标能力
- **THEN** 左侧显示该能力可选择的合法 Unit 目标；没有合法目标时显示中文空状态，不提交能力

#### Scenario: 选择目标打开能力确认
- **WHEN** 玩家点击目标列表中的一行
- **THEN** 该目标成为待确认目标并显示预览，同时打开能力确认窗口；不扣 AP、不触发效果

#### Scenario: 确认有效目标
- **WHEN** 玩家确认待执行的能力与目标，且回合、单位、能力和目标仍有效
- **THEN** 系统关闭确认窗口并通过能力系统提交且仅提交一次

#### Scenario: 确认时目标或能力失效
- **WHEN** 确认前待用单位、能力、回合或目标已失效，或能力已不可用
- **THEN** 系统不激活、不额外扣 AP，关闭过期确认并刷新能力与目标状态

#### Scenario: 取消能力确认
- **WHEN** 玩家取消能力确认
- **THEN** 系统不激活能力、不扣 AP，关闭确认窗口并返回目标选择，保留仍合法的目标供继续选择

#### Scenario: 玩家选择动作清除待用能力
- **WHEN** 目标选择或能力确认期间玩家切换单位、取消选择，或再次点击当前已选中的玩家单位
- **THEN** 系统清除待用能力和目标、关闭目标列表与能力确认窗口，并刷新当前选中单位的信息和能力状态
