# Spec Delta

## MODIFIED Requirements

### Requirement: 左侧列表只显示当前单位的可瞄准敌人

系统 SHALL 在屏幕左侧的交互 Canvas 中显示当前选中且可下达命令的己方单位对应的可瞄准敌人列表；列表只包含存活、已登记在棋盘、非中立敌对、在攻击者当前 SightRange 内、LOS 畅通且射击能力可检查的目标，并按稳定顺序显示中文目标名称。视野距离 SHALL 使用 `floor(sqrt(dx² + dy²))`，不得额外应用固定武器射程或按命中率筛除目标；列表目标是否合法与当前是否有足够 AP 开火分别判断。

#### Scenario: 选中己方单位后生成列表

- **WHEN** 用户选中一个存活且处于玩家回合的己方单位
- **THEN** 左侧交互列表刷新为该单位当前可瞄准的敌人，并以中文显示目标名称；没有目标时显示中文空列表状态

#### Scenario: 切换己方单位

- **WHEN** 用户选中另一个己方单位
- **THEN** 列表立即替换为新单位的可瞄准敌人，之前的目标选择和命中率展示不再沿用

#### Scenario: 目标状态改变

- **WHEN** 单位移动、攻击者 SightRange 变化、障碍/LOS 变化、回合切换、AP 变化或单位死亡
- **THEN** 列表和开火状态刷新，移除不再合法的目标；仅 AP 不足不改变目标的视野合法性

#### Scenario: 不同单位具有不同视野

- **WHEN** 同一敌人距离两名己方单位均为 10 格且 LOS 畅通，其中一名 SightRange 为 12，另一名为 9
- **THEN** 选中前者时列表包含该敌人，切换至后者时列表不包含该敌人，并清除原目标选择

#### Scenario: 零命中率的可见敌人

- **WHEN** 目标在当前单位 SightRange 内且 LOS 畅通，其他目标条件满足，但最终命中率为 0%
- **THEN** 该目标仍显示在列表中并可选中；AP 和能力条件满足时仍可开火

### Requirement: 点击列表项只切换射击目标

系统 SHALL 允许用户通过交互 Canvas 中的左侧列表项选择目标，并显示该目标的中文名称与最终命中率 `clamp(Aim - Defense + 距离曲线修正, 0, 100)`；UI 只渲染能力提供的预览，不自行计算距离、视野或命中公式。列表项事件 SHALL 交给 UI 控制器处理，切换列表项不得直接扣 AP、造成伤害或触发射击。

#### Scenario: 选择一个列表目标

- **WHEN** 用户点击一个可瞄准敌人的列表项
- **THEN** 该项成为当前射击目标，界面以中文显示目标名称和包含距离修正的最终命中率，AP 保持不变

#### Scenario: 距离或属性变化后刷新命中率

- **WHEN** 已选目标仍合法，但移动跨过距离曲线阶梯边界，或 Aim、Defense 发生变化
- **THEN** 界面更新该目标的最终命中率，不触发射击；状态未继续变化时，之后开火使用的概率与显示值一致

#### Scenario: 选择失效目标

- **WHEN** 已选目标在点击后死亡、离开棋盘或因移动、SightRange 变化、LOS 阻挡而失效
- **THEN** 界面清除该目标选择并隐藏开火按钮

### Requirement: 开火按钮只在目标有效时可用

系统 SHALL 仅在存在当前选中的合法目标、攻击者仍有至少 1 AP 且射击能力可以激活时，在交互 Canvas 中显示并启用中文开火按钮；点击按钮 SHALL 通过 UI 控制器调用射击执行流程，而不是由目标列表或单位点击直接开火。

#### Scenario: 合法目标显示开火按钮

- **WHEN** 当前选中目标通过全部射击检查且攻击者 AP 足够
- **THEN** 中文开火按钮显示并可点击

#### Scenario: 没有合法目标时隐藏按钮

- **WHEN** 没有选中目标、目标列表为空、攻击者不是玩家回合或 AP 不足
- **THEN** 开火按钮隐藏或不可交互，且点击无射击效果

#### Scenario: 点击开火后刷新界面

- **WHEN** 用户点击可用的开火按钮
- **THEN** 系统执行一次射击并以中文刷新 AP、命中结果、目标生命值和列表；目标死亡时从列表移除并清除选择
